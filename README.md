# bazis-monitor — бот «Мониторинг» и дашборд доступности Базиса

Алертный Telegram-бот и дашборд в духе Grafana для прода Базиса `etalon.iflat.io`. Работает на Cloudflare: Worker `bazis-monitor`, база D1 и Cron раз в минуту.

- **Проверки.** Раз в 5 минут бот проверяет сайт (`/login`) и API (`/api/v1/houses`). При сбое — каждую минуту.
- **Тревога.** Когда прод падает, бот пишет в тему «СЕРВИС НЕ ДОСТУПЕН» чата разработчиков и упоминает дежурных. Напоминает, пока кто-то не нажмёт «🙋 Беру».
- **Статистика.** Бот считает доступность, ведёт журнал падений с разборами и показывает всё это на дашборде по ссылке из бота.

Каждый понедельник в 9:00 бот присылает в тему тревог **итоги недели картинкой** (доступность, падения, столбики по дням) с кнопкой на дашборд. Прислать отчёт вручную — команда `/weekly`.

Текущая версия — **1.4.0**. Что менялось — в [CHANGELOG.md](CHANGELOG.md). Готовый файл для Cloudflare лежит в [релизах](https://github.com/LuzanIV/bazis-monitor/releases). Подробное описание — в [docs/bot-monitoring-bazis.md](docs/bot-monitoring-bazis.md), инструкция для чата — в [docs/instrukciya-dlya-chata.md](docs/instrukciya-dlya-chata.md).

## Установка

Нужен Node.js 22.13 или новее: тесты используют `node:sqlite`.

```sh
npm ci                                # miniflare и playwright
npx playwright install chromium       # браузер для скриншотов и картинок, один раз
```

## Сборка и проверка

```sh
npm run build          # → dist/worker.js, один файл для Cloudflare
npm test               # сборка + 31 сценарий
npm run test:workerd   # сборка + прогон в рантайме Cloudflare
npm run preview        # сборка + скриншоты дашборда в test/shots/
npm run card           # пример карточки «итоги недели» → test/shots/week-card*.png
npm run art            # картинки бота: art/avatar.png, art/description.png, app/icon.png
npm run card-font      # пересобрать атлас шрифта карточки → app/card-font.json
```

## Выкладка на прод

1. Возьмите `worker-X.Y.Z.js` из [релиза](https://github.com/LuzanIV/bazis-monitor/releases) или соберите `npm run build` → `dist/worker.js`.
2. Cloudflare → Workers & Pages → `bazis-monitor` → Edit code. Выделите весь код, вставьте новый, нажмите Deploy.
3. Проверьте `https://bazis-monitor.luzaniv.workers.dev/health`: в ответе должно быть `"version":"X.Y.Z"`.

Если Worker поднимается с нуля:

1. Создайте Worker и привяжите базу D1 под именем `DB`.
2. Внесите секрет `BOT_TOKEN` — токен от @BotFather. Это единственный секрет: ключ вебхука и админ-ключ выводятся из него.
3. Вставьте код и нажмите Deploy.
4. Добавьте Cron Trigger `* * * * *`.
5. Откройте `/setup`, нажмите Start в боте, добавьте бота в чат разработчиков.
6. В теме тревог напишите `/bind`.
7. Сделайте бота админом с правами:
   - закреплять сообщения;
   - управлять темами;
   - удалять сообщения.

В репозитории нет токенов и ключей. Секрет живёт только в Cloudflare.

## Как вносить изменения

1. Правка в коде → `npm test` и `npm run test:workerd`.
2. Новая версия в `src/00-config.js` (`VERSION`) и в `package.json`.
3. Запись в [CHANGELOG.md](CHANGELOG.md): раздел `## [X.Y.Z] — ГГГГ-ММ-ДД` с подразделами «Добавлено», «Изменено», «Исправлено». Внизу файла — ссылка на релиз.
4. Загрузка изменённых файлов на GitHub. Одна папка — один коммит «X.Y.Z: …».
5. Релиз `vX.Y.Z` от `main`:
   - текст — раздел версии из журнала;
   - файлы — `worker-X.Y.Z.js` и, если менялись, картинки.
6. Выкладка в Cloudflare и проверка `/health`.
7. Обновить копию исходников в проекте Claude «Цифровой контур девелопмента / Строительный контроль» (`claude/bazis-monitor/…`) и документ бота. Новые чаты читают код оттуда: закрытый репозиторий им недоступен.
